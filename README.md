# 车票模拟 · 仅供收藏
按真实火车票的文字版面，版面的每个墨迹框都是从实拍参考票上逐像素量测得到的。
所有文字都能改，只有 `仅供收藏使用` 这一处是固定文案、不可编辑。

直接双击 `index.html` 即可打开编辑器。

---

## 快速开始

直接用浏览器打开 `index.html` 即可（无需构建、无需联网、无需服务器）。

```
Railway Ticket/
├─ index.html            编辑器页面（双击打开）
├─ styles.css
├─ js/
│  ├─ qrcode.js          ★ 自带 QR 编码器（字节模式 / L,M,Q,H / 版本 1~40 自动）
│  ├─ layout.js          ★ 版式定义：每个字段的墨迹框 / 字号 / 压缩系数 / 是否可编辑
│  ├─ render.js          ★ 渲染器：把数据画到 canvas（导出即所见）
│  └─ app.js             交互层：点选、就地编辑、导出 PNG / JSON
├─ assets/
│  ├─ ticket-blank.webp  红票空白底图
│  ├─ Blue ticket.png    蓝票底图
│  ├─ CR450.png          CR450 版底图
│  └─ bg-data.js         三张底图的内联 data URL（保证 file:// 下也能导出 PNG）
├─ ticket-layout.json    ★ 纯数据版式（给 React Native / Flutter / 原生端直接读取）
└─ README.md
```

> 量测、校准、二维码校验、成品渲染这些**开发期脚本不随项目分发**，已移到项目外的
> `RailwayTicket-dev-backup-*/` 目录里保存（其中脱敏版可随时放回 `tools/` 使用）。

功能：

| 操作 | 说明 |
| --- | --- |
| 打开页面 | **票面与面板都是空的**：只有固定文案、固定符号（`检票:`、`¥`、`元`）与版面装饰 |
| 清空 | 一键清空所有可编辑内容 |
| 导出校验 | 票面信息全部必填；缺项时弹窗列出未填内容并可点击跳转，不导出 |
| 点票面文字 | 就地出现输入框，所见即所得地改字；`Enter` 提交，`Esc` 取消 |
| 点固定标语 | 在预设选项之间循环切换（如虚线框内的标语），右侧面板另有下拉框 |
| 右侧面板 | 按「票面信息 / 行程信息 / 乘客信息 / 固定文案」分组，逐项编辑 |
| 显示编辑区 | 切换票面上可编辑区域的红框提示 |
| 导出 PNG | 1x / 2x / 3x，可选白底或透明底；文件名 = **车次 + 模板后缀**；保存进 **「下载/Ticket」**，不支持的浏览器自动改用浏览器下载（详见下节） |
| 导出 / 导入 JSON | 版式 + 数据整体导出，可再导入 |
| 二维码 | **按 `https://rail.re/# + 车次` 实时生成**，改车次即时重算；也可上传图片覆盖 |



## 导出：保存位置与文件名

**保存位置**（三级，任一级不可用或失败就自动降级，不需要手动切换）：

| 顺序 | 方式 | 适用环境 | 落地位置 |
| --- | --- | --- | --- |
| 1 | 目录句柄直接写入 | 桌面 Chrome / Edge | `…/下载/Ticket/车次.png` |
| 2 | 系统「另存为」对话框 | 支持 `showSaveFilePicker` 的浏览器 | 用户自选 |
| 3 | 浏览器自身下载 | 手机浏览器 / Firefox / Safari | 浏览器的下载目录 |

* 第 1 级首次会弹一次目录授权，对话框默认就停在「下载」；授权后**在该目录下自动新建 `Ticket`
  子目录**并写入，导出文件不会和下载文件夹里的其它内容混在一起。
* 手机端没有目录写入 API，会自动走第 3 级（浏览器下载），不会再出现提示之后什么都没发生的情况。
* 面板右上角「上次导出」会显示文件名、体积与落地方式，并提供「再存一次 / 新标签页打开 / 另存为…」。
